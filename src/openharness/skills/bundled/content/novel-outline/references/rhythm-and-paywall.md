# 节奏曲线与付费卡点规划

> 学习来源：短剧流量分发机制、付费留存转化漏斗模型及商业微短剧编剧实战。

短剧本质是「以秒计的注意力经济」。大纲在规划分集与爽点时，必须建立在成熟的节奏曲线与商业卡点逻辑之上。

---

## 一、 四段式全剧节奏曲线

整部短剧的分集规划应遵循 **起势段(15%) ➔ 攀升段(30%) ➔ 风暴段(35%) ➔ 决战段(20%)** 的黄金律：

```
情绪势能
  ▲
  │                                    ★ 终极高潮 (倒数第2-3集)
  │                              ╭───╯\
  │                      ▲      │      \
  │                     / \  ╭──╯       \ 结局余韵
  │             ▲      /   \/
  │            / \    /    风暴段(35%)   决战段(20%)
  │    ★      /   \──╯
  │   / \    /   攀升段(30%)
  │  /   └──╯
  │ /   起势段(15%) [首波付费墙]
  └────────────────────────────────────────────────► 集数进程
```

以标准的 60 集微短剧为例：

### 1. 起势段（第 1–9 集 · 约占 15%）
- **核心任务**：
  - 第 1 集前 3 拍在运动中给出致命钩子，立刻建立观众共情与危机感；
  - 迅速引入小反派，让主角陷入极具不公的困境（受辱、背叛、危机）；
  - 在第 3–5 集完成第一次反击试探，释放微型爽点；
  - **第 8–10 集引爆全剧第一个大爆点（`major` 爽点）**，并完美承接第一道核心付费墙。

### 2. 攀升段（第 10–27 集 · 约占 30%）
- **核心任务**：
  - 解决小反派，中反派正式登场并带来更大的阶层压迫；
  - 主角展开多线对抗，揭示更多隐藏技能或中级底牌；
  - 严格保持 **爽点间隔 ≤ 3 集无真空**，通过「小打脸 ➔ 危机升级 ➔ 再次打脸」维持高频粘性；
  - 在第 16 集、第 24 集等关键节点设立二级付费卡点。

### 3. 风暴段（第 28–48 集 · 约占 35%）
- **核心任务**：
  - 核心矛盾全面激化，大反派动用终极资源展开毁灭性打击；
  - 主角遭遇全剧的**至暗时刻**（盟友被抓、身世被污蔑、重要资产被夺走）；
  - 情绪势能不断压缩蓄力，观众紧迫感达到顶点；
  - 在第 32 集、第 40 集、第 48 集设立深水区付费卡点。

### 4. 决战段（第 49–60 集 · 约占 20%）
- **核心任务**：
  - 主角冲破至暗时刻，反击号角吹响，亮出全部绝杀底牌；
  - 大反派全线崩盘，完成最彻底的清算与打脸；
  - 隐藏反派现形并被迅速解决；
  - **注意硬规则**：大爆点（major beat）绝不能压在最后一集（第 60 集），高潮通常在第 57–58 集引爆，最后一两集用于回收伏笔与情感圆满。

## 二、 付费卡点（Paywall）科学规划

微短剧的商业变现依赖于卡点悬念。大纲阶段就要预留卡点位置，为后续投流与付费转化打下地基：

### 1. 卡点密度与分布
- **黄金占比**：付费卡点集数占总集数的 **10%–15%**。
- **60 集短剧典型配置**（建议 6–8 个卡点）：
  - **首道卡点（生死线）**：第 8–10 集。此处留存决定剧集盈亏，必须是全剧最抓人的强反转或身份即将揭破的一刹那；
  - **次轮卡点**：第 15–18 集、第 24–26 集；
  - **中局卡点**：第 33–35 集、第 42–44 集；
  - **决战前夕卡点**：第 50–52 集。

### 2. 付费卡点的四大设计绝杀
1. **刀锋悬停**：反派巴掌即将扇到亲人脸上的前一秒；主角的手突然从暗处握住反派手腕，卡点黑屏。
2. **大招蓄力**：反派正嘲讽主角一无所有，主角冷冷拿出一份机密文件，对方脸色剧变，主角刚要开口宣读，卡点黑屏。
3. **生死倒计时**：炸弹/毒发/抢救室只剩最后 10 秒，主角赶到门外，手握把手猛推，卡点黑屏。
4. **身份揭穿前夕**：当着全城名流的面，老太爷颤抖着揭开主角身后的勋章/胎记，惊呼出“您难道是……”瞬间卡点黑屏。

**避坑指南**：绝不能在两集之间的寒暄、赶路、吃茶等平静过渡处设卡点。没有强情绪悬念的卡点会导致极高断播率。
