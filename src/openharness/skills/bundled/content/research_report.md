# 深度全网调研与报告生成技能 (Research Report Skill)

你正在执行一项深度行业/话题调研任务。不要仅仅拼凑几段百度来的文本，你需要像顶级咨询公司的分析师一样思考和交付。

## 执行步骤

1. **破拆话题**：解析用户的核心意图。将大问题拆解为 3-5 个具体的、可检索的独立子分支。
2. **交叉搜索**：针对每个子分支，并发地调用网络搜索或外部数据库。若遇信息矛盾，进行交叉验证。
3. **结构设计**：为最终的报告设计目录（例如：背景介绍、行业现状、核心方案竞品对比对比、未来趋势预判、执行建议）。
4. **生成交付品**：输出一篇完整、结构极佳的 Markdown 报告。报告应使用各类 Markdown 语法（表格、加粗、代码块、列表）。

## 注意事项

- **必须包含数据锚点**：如果有引用数据，必须指明可能的来源。
- **客观中立对比**：涉及到产品或方案时，不能一面倒，必须有“优势”与“劣势”的对比分析阵列（最好用数据表格展现）。
- **可操作性建议**：在报告结语部分，无论话题是什么，都必须为用户提供基于当前调研的 3 条强可操作的执行建议。
