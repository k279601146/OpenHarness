# 短剧带货广告

## 定位与边界

将商品卖点转化为具有明确冲突、反转、产品证明和行动召唤的短剧带货视频。技能负责需求采集、剧情创意、资产规划、分镜编排、生成任务组织、确认门禁和质量验收；具体图片、视频、配音和音乐生成由当前可用的媒体能力执行。

不得把未经用户确认的商品属性、价格、材质等级、功效、产地、奖项、销量、人物身份或品牌关系写成事实。不得使用明显虚假对比、绝对化承诺、羞辱消费者、歧视性身份标签或无法证明的表达。剧情中的“打脸”应服务于商品卖点展示，不应升级为人身攻击。

## 核心流程

严格按以下阶段推进。每个阶段完成后再进入下一阶段；用户要求修改时回填已有状态，不重新开始。

| 阶段 | 目标 | 必须产物 | 是否需要用户确认 |
|---|---|---|---:|
| Step 0 需求采集 | 收集商品、卖点和视频约束 | 结构化创作表单 | 是 |
| Step 1 剧情规划 | 形成冲突、反转、证明和 CTA | 15 秒极速大纲，或 30 秒以上专业剧本 | 15 秒展示大纲；30 秒以上必须确认完整剧本 |
| Step 2 资产来源确认 | 确定角色图、场景图、商品图的生成或上传方式 | 资产来源表 | 是 |
| Step 3 角色资产 | 生成/接收角色模特图并展示 | 角色模特库 | 是 |
| Step 4 场景资产 | 选择场景风格并生成/接收场景图 | 场景素材库 | 是 |
| Step 5 分镜与视频任务 | 组织镜头、参考图和生成参数 | 分镜视频库、视频任务 | 付费/受限生成前必须确认 |
| Step 6 结果验收 | 检查商品、卖点、连续性和交付规格 | 成片、分镜、问题清单 | 否；失败时给恢复选项 |

## Step 0：使用 ask_user_form 一次性采集

必须使用 `ask_user_form` 一次性采集完整需求，不要用多轮自由文本逐项追问。优先为每个字段提供高频建议选项，以降低填写成本；同时为需要特殊处理的用户保留同字段内的“自定义”输入项。选择“自定义”后必须立即展示对应的 text/textarea/number 输入，不得要求用户提交后再通过聊天补充。

表单应按“商品信息”“剧情创意”“角色与场景”“视频规格”“声音与交付”分组，并显示必填标识、字段说明、选项描述、上传入口和进度。修改任务使用上次 State 回填默认值，用户只改一个字段时执行 Patch。

表单字段如下：

| 字段 | 类型 | 必填 | 校验规则 | 默认值 |
|---|---|---:|---|---|
| `product_name` | text | 是 | 1–100 字 | 新建为空；修改时回填 |
| `product_category` | select + custom text | 是 | 建议选项：服装、美妆、珠宝、家居、食品、数码；另提供“自定义”输入 | 同上 |
| `product_images` | file[] | 是 | 至少 1 张；最多 8 张；优先白底图、正面图或细节图 | 同上 |
| `product_claims` | textarea | 是 | 1–500 字；逐条列出可验证卖点 | 同上 |
| `brand_tone` | select + custom text | 否 | 建议选项：低调奢侈、轻奢、亲民、专业、活泼；另提供“自定义”输入 | 低调奢侈 |
| `story_angle` | select + custom text | 是 | 建议选项：快速反转打脸、身份反差、误会澄清、前后对比、挑战测试；另提供“自定义”输入 | 快速反转打脸 |
| `characters` | textarea | 是 | 角色数量、身份、年龄段、关系和冲突立场 | 同上 |
| `setting` | textarea | 是 | 场景、时代、空间和氛围 | 同上 |
| `video_language` | select + custom text | 是 | 建议选项：中文、英文、日文、韩文；另提供“自定义语言”输入 | 中文 |
| `video_duration` | select + custom number | 是 | 固定建议选项：`10s`、`15s`、`30s`、`自定义`；选择自定义后输入正整数秒数，范围 1–180 秒 | 15s |
| `video_ratio` | select + custom text | 是 | 建议选项：9:16、1:1、16:9；另提供“自定义比例”输入 | 9:16 |
| `voice_style` | select + custom text | 否 | 建议选项：女声、男声、旁白、角色对白、无配音；另提供自定义描述 | 根据剧情自动建议 |
| `subtitle_requirement` | select + custom text | 否 | 建议选项：需要、不要、待定；另提供自定义样式输入 | 需要 |
| `cta` | text | 是 | 1–80 字；如“立即购买”“点击了解” | 根据渠道建议并待确认 |
| `reference_style` | file[]/text | 否 | 最多 5 个参考文件或文字描述 | 无 |
| `must_include` / `must_avoid` | textarea | 否 | 必须出现和禁止出现的元素或表述 | 无 |
| `generation_preferences` | select + custom textarea | 否 | 建议选项：标准画质、高清、写实、商业广告感、电影感；可多选并提供自定义输入 | 当前能力的最低必要规格 |

`ask_user_form` 提交后必须执行字段校验，并展示结构化回显，包括商品名、已确认卖点、故事角度、角色、场景、时长、比例、语言、CTA 和待确认事项。自定义字段必须展示具体填写内容，不得只显示“自定义”。用户选择“上一步”时使用旧值回填；用户说“只改时长/角色/场景”等，执行字段级 Patch，其他字段保持不变。

## Step 1：按时长分支规划剧情

**时长是生产流程的硬分支，必须先判断 `video_duration`，再决定是否进入完整剧本步骤。**当前视频生成能力普遍以单个 15 秒片段为基本生成单位，因此 30 秒及以上的视频不得直接当作一个单任务提交。

### 10 秒与 15 秒极速模式

当 `video_duration IN [10s, 15s]` 时，允许跳过完整剧本文档，直接生成高密度极速大纲和分镜。10 秒建议 2–3 个镜头，15 秒建议 3–4 个镜头；大纲仍必须包含 Hook、商品卖点证据、反转或结果反馈和 CTA。资产确认完成后，可进入视频生成前确认。

### 30 秒与自定义长时长专业剧本模式

当选择 `30s`，或选择“自定义”且输入时长大于 15 秒时，**不得跳过剧本步骤**。必须先完成以下动作：

1. 撰写高信息密度专业短剧剧本，并落库为独立版本，例如 `script_v1`。
2. 在剧本开头列出 `出场人物` 和 `场景设定`，随后给出剧情大纲、分段节奏、完整台词/旁白、商品卖点植入、镜头调度和结尾 CTA。
3. 将剧本以只读回显形式展示给用户，提供“确认剧本”“返回修改”“取消”选项。
4. 只有用户明确确认剧本后，才能生成分镜并进入视频生成；如果当前工作区没有独立的视频合成工具，不要在技能里硬性要求自动合片。
5. 用户修改剧本时创建新版本并保留旧版本；未确认的剧本不得进入任何高成本媒体生成动作。

30 秒标准剧本结构：

```text
标题：
视频时长/比例/语言：

出场人物：
- 人物名：年龄段、身份、外观、性格、剧情功能

场景设定：
- 地点、时间、空间风格、光线、关键道具

剧情大纲：
- 误判/冲突：
- 商品线索：
- 阻碍升级：
- 反转证明：
- 产品展示与 CTA：

分段节奏：
- 0–15 秒：
- 15–30 秒：

完整台词与旁白：
镜头与商品证据：
字幕、音效和音乐方向：
合规与待确认信息：
```

30 秒及以上的自定义时长沿用同一结构，并根据总时长向上拆分为多个 15 秒片段；最后一个片段可以短于 15 秒，但必须在任务确认中显示实际时长。每段必须有独立小目标，并注明与前后段的衔接锚点。剧本内容必须与用户已确认的商品事实一致，不得为了制造反转擅自添加价格、身份、材质等级或功效。

默认采用四段式因果链：

1. **误判或低谷**：在前 0–3 秒建立身份误判、审美偏见、价格误会或场景冲突，但避免侮辱真实群体。
2. **商品线索**：通过面料、剪裁、质感、细节、包装、工艺或使用场景埋下产品证据，不要只靠旁白宣称。
3. **快速反转**：由店长、专业人士、熟客、细节特写或真实行为揭示商品价值；反转必须与商品卖点直接相关。
4. **体面收束与 CTA**：主角保持克制，产品成为视觉焦点，结尾用一句可读 CTA 完成转化。

10 秒默认镜头节奏：

| 时间 | 作用 | 画面要求 |
|---|---|---|
| 0–2 秒 | Hook/冲突 | 立刻出现误判、强结果或商品视觉冲击 |
| 2–6 秒 | 卖点证明 | 用一个核心细节或动作证明卖点 |
| 6–10 秒 | 反转/CTA | 快速收束并展示商品与行动召唤 |

15 秒默认镜头节奏：

| 时间 | 作用 | 画面要求 |
|---|---|---|
| 0–3 秒 | Hook/冲突 | 明确误判、质疑或强结果；观众无需背景知识即可理解 |
| 3–7 秒 | 卖点线索 | 商品穿着/使用状态、材质或关键细节特写 |
| 7–11 秒 | 反转证明 | 用人物反应、工艺证据或场景关系完成反转 |
| 11–15 秒 | 商品与 CTA | 清楚展示商品、品牌信息和行动召唤 |

30 秒分段默认策略：

| 片段 | 时长 | 内容职责 | 生成前置 |
|---|---:|---|---|
| `segment_01` | 15 秒 | 人物出场、场景冲突、商品线索和第一处悬念 | 已确认专业剧本、角色锚点、场景锚点、商品锚点 |
| `segment_02` | 15 秒 | 反转证明、商品细节、人物反应、CTA | 已确认剧本；复用前段视觉锚点；准备合片衔接 |

选择 30 秒时拆成 2 个 15 秒片段。选择“自定义”且时长大于 15 秒时，按 `ceil(目标秒数 / 15)` 拆分；每个片段必须单独登记任务、状态和输出资源，不能把多个片段误报为一个原生长视频生成任务。

当所有视频片段完成后，再执行音乐/音效合成和多段合片。音乐方向可以在剧本阶段确定，但不得在剧本确认前触发高成本音乐生成。

## 商品卖点转视觉证据

先把用户的每条卖点转换成可拍摄证据，再写台词：

| 卖点类型 | 视觉证明方式 | 谨慎规则 |
|---|---|---|
| 材质/面料 | 纤维、织纹、垂坠、触感动作、细节微距 | 不擅自增加材质等级或检测结论 |
| 剪裁/版型 | 上身轮廓、肩线、袖口、行走动态、前后对比 | 不承诺“显瘦/增高”等绝对效果 |
| 工艺 | 走线、领口、纽扣、内里、包装和手部操作 | 工坊/高定等信息必须来自用户 |
| 保暖/舒适 | 室内外场景、穿着动作、轻盈叠穿 | 功效和倍数只能使用已确认表述 |
| 低调奢侈 | 无 Logo 质感、色彩、空间、人物姿态和克制反应 | 不用价格羞辱或炫富对比替代产品证明 |

## Step 2：角色、场景和商品资产确认

剧情规划后，必须向用户确认资产获取方式。每个关键资产使用 `AI 生成`、`用户上传` 或 `使用已有资产` 三选一。不得把“有无素材”作为唯一问题。

角色资产字段至少包含：角色名、叙事功能、年龄段、外观、服装、表情、姿态、发型、镜头用途、是否需要全身白底图。主角和对立角色应分别确认。商品资产至少包含白底图、细节图、上身图或包装图中的可用项。

场景资产字段至少包含：场景名、空间类型、时间、光线、色彩、材质、镜头用途、是否需要无人物背景。对服装类低调奢侈广告，可建议米白大理石、黄铜陈列架、柔和暖光、克制陈列等风格，但只能作为建议，须让用户确认。

如用户选择 AI 生成：读取用户指定的风格资源或风格 ID 的使用说明；不编造不存在的风格参数。先确认可用图像模型、比例和生成数量，再提交生成任务。角色图优先生成统一视角的全身或半身参考图；场景图优先生成无人物背景；商品图保持款式、颜色、Logo 和结构一致。生成后展示结果，让用户确认“满意/需要重生成/指定修改项”，未确认不得进入视频生成。

如用户选择上传：引导上传文件并记录稳定资源引用；不得使用临时 blob、data URL、provider URL 或宿主机路径作为长期引用。

## 画布分组规则

若当前工作区支持画布分组，按以下顺序创建并使用：

1. `角色模特库`：存放主角、配角和群演角色参考图。
2. `场景素材库`：存放店铺、街道、家居、活动现场等背景参考图。
3. `商品资产库`：存放白底图、细节图、包装图和 Logo 资产。
4. `分镜视频库`：存放分镜草图、片段、合成视频和最终版本。

需要执行“创建画布分组”时，先单独完成分组创建；下一轮再调用图片或视频生成。创建完成后，把生成结果归入对应分组，并在 State 中记录资源 ID、来源、版本和确认状态。若当前环境不支持画布，使用等价的任务资源分组，不要因缺少画布而中断创作。

## Step 3–5：资产、分镜与视频生成

资产确认后，先输出分镜计划，再进入视频生成。这里的字段是规划字段，不是工具输入 JSON；不要在技能里固定请求形状，也不要把不存在的“音乐生成/视频合片”工具写成必经步骤。

每个镜头建议记录这些规划项：

- `shot_id`
- `time_range`
- `purpose`
- `visual`
- `action`
- `camera`
- `dialogue`
- `subtitle`
- `sound`
- `asset_refs`
- `selling_point_proof`
- `continuity`
- `safety_note`

视频生成时，按当前可用的 `generate_video` 能力组织请求：

- 10 秒与 15 秒任务通常直接生成单段成片。
- 30 秒及以上任务拆成多个不超过 15 秒的片段分别生成。
- 角色、场景、商品参考图要作为稳定引用传入，并在 brief 中说明各自用途。
- 音乐/音效意图写进 prompt 或 brief，不要假设这里一定有独立的音乐生成工具。
- 如果当前工作区没有视频合成/合片工具，就不要在技能里强制要求自动合片；交付分段成片、分镜和剪辑顺序说明即可。

生成任务提交前，若涉及会员能力、额度、付费资源或高成本模型，必须展示确认卡，至少说明任务数量、每个片段的时长、目标总时长、比例、清晰度、版本数和系统提供的消耗提示。30 秒任务应明确展示“2 个 15 秒视频生成任务”的执行计划。没有用户明确确认，不得触发任何剩余生成任务；“确认并记住本项目选择”只适用于用户明确授权的同一项目后续任务，仍需遵守系统权限和额度限制。


状态操作规则：新任务执行 `Init`；返回修改执行 `Hydrate`；单字段修改执行 `Patch`；用户确认资产后将对应 `confirmed` 设为 `true`；生成失败保留已完成资产和节点，允许从失败节点重试。



## 失败处理与质量门

| 问题 | 处理方式 |
|---|---|
| 必填字段缺失 | 回到表单并定位字段 |
| 商品图缺失/不可用 | 请求上传、替换或确认使用生成的概念商品图 |
| 角色/场景图不满意 | 只重生成指定资产，保留已确认资产 |
| 权限或额度不足 | 提供降级规格、减少版本、稍后重试或终止；不得绕过限制 |
| 内容安全拦截 | 修改相关台词/冲突表达或终止；不得强制继续 |
| 剧本未确认 | 停留在剧本确认页，不得生成片段、音乐或合片 | 
| 片段生成失败 | 保留剧本、资产和已完成片段，从失败片段重试或交付部分结果 |
| 音乐/合片或后处理不可用 | 保留全部视频片段，单独重试可用的后处理步骤；如果当前环境没有合片工具，则只交付已完成片段和剪辑顺序 |
| 视频生成失败 | 保留分镜和已完成资产，从失败片段重试或只交付脚本 |
