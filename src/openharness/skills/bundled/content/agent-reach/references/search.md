# Search Route

Use this route for public web search, semantic search, technical search, source discovery, and broad topic research.

## Scope

- Public web pages
- Official docs and release notes
- Public reports and white papers
- Public technical blogs
- Public code or repository context

## Process

1. Translate the user's question into two or more targeted search queries.
2. Prefer primary sources first: official docs, standards, research papers, company posts, repository docs, and release notes.
3. Add credible secondary sources when they explain context or tradeoffs.
4. Track source freshness and jurisdiction/region when relevant.
5. Summarize findings with citations and open questions.

## Output

- Query plan
- Source list with links
- Key findings
- Contradictions or uncertainty
- Recommended next searches

## Boundary

Do not automate login-gated search surfaces, bypass rate limits, or bulk extract pages. If better results require a user-owned local search provider, say so without asking for credentials in chat.
