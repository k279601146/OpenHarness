# Web and RSS Route

Use this route for public URL reading, article digestion, documentation review, public reports, and RSS/Atom feed analysis.

## Public URL Reading

For each user-provided public URL:

1. Identify source type: article, docs, report, paper, landing page, changelog, or forum page.
2. Extract title, author/publisher if available, date if available, and canonical link.
3. Summarize structure and key claims.
4. Preserve important links and references.
5. Note paywall/login/gating limitations instead of trying to bypass them.

## RSS / Feed Analysis

For public feeds:

1. Parse recent entries.
2. Group by topic.
3. Identify repeated stories and unique updates.
4. Highlight dates, source names, and links.
5. Suggest watch keywords.

## Output

- Source metadata
- Section summary
- Evidence table
- Bias/freshness notes
- Follow-up questions

## Boundary

Do not provide methods for bypassing paywalls, CAPTCHA, anti-bot systems, or login walls. Do not ask for cookies or private headers.
