# Public Video and Podcast Route

Use this route for public video, public podcast, transcript, subtitle, and media-note research.

## Scope

- User-provided public YouTube/Bilibili/video links
- Public podcast episode pages
- Public transcripts or subtitles when available
- Public metadata, chapters, titles, descriptions, and linked resources

## Process

1. Identify media source, title, creator/channel, publish date, duration, and URL.
2. Prefer existing public transcripts/subtitles or user-provided transcript text.
3. If no transcript is available, state the limitation and ask whether the user can provide transcript/audio material.
4. Summarize content structure, key points, notable timestamps when available, and follow-up resources.

## Output

- Media metadata
- Chapter or segment summary
- Key arguments
- Useful short excerpts when needed
- Source links
- Follow-up resources

## Boundary

Do not package downloaders, account automation, logged-in browser reuse, or bypass instructions. Do not fetch private, member-only, or login-only videos. Do not extract comments in bulk.
