# Public Community Route

Use this route for summarizing public community discussion that the user provides or that is publicly reachable without login.

## Scope

- Public forum pages
- Public discussion threads
- Public Q&A pages
- Public community posts shared by the user
- Public product feedback pages

Examples of possible public communities include V2EX, Reddit pages that are publicly visible, Twitter/X public links, Bilibili public video pages, public LinkedIn/company pages, product forums, and similar public sources.

## Process

1. Confirm whether the source is public and reachable without private login.
2. Read only the visible public content.
3. Group opinions by theme.
4. Separate representative views, repeated complaints, praise, edge cases, and unsupported claims.
5. Preserve source links and note sampling limitations.

## Output

- Topic summary
- Positive signals
- Negative signals
- Representative public links
- Confidence and sampling limitations
- Follow-up verification plan

## Boundary

Do not ask for cookies, login state, browser session reuse, private account access, proxy setup, or CAPTCHA/anti-bot bypass. Do not automate bulk collection of account timelines, followers, comments, private groups, or gated content. If content is unavailable publicly, say so and propose public alternatives.
