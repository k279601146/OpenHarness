# Agent Reach dev2 Adapter

This is the English companion document for the dev2 bundled Agent Reach skill.

Use `$agent-reach` for public-source internet research, public URL reading, public GitHub research, RSS/source tracking, public video or podcast note-taking, public competitor research, technical evaluation, and fact checking.

The dev2 adapter keeps the upstream Agent Reach routing model but does not bundle executable platform collectors, cookies, login state, proxy setup, credential collection, anti-bot bypass, or bulk account-content collection.

Read `SKILL.md` first. Load only the relevant file under `references/` for the active route.
