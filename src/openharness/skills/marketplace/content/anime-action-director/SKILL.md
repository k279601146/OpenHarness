# 动画战斗导演

## 适用与分流

用于原创角色的动画打斗、追逐、能力展示和游戏过场。若重点是角色立绘或服装设计，转交角色设计技能；若要现实格斗训练，拒绝可模仿伤害步骤并改为非教学化表演。引用某动画时提炼线条、节奏、镜头和色彩原则，不复制人物、招式名称或标志性构图。

## 动作导演诊断

先确定动作目的：逃脱、保护、争夺、展示能力还是情绪决裂。回答：谁主动、谁反应？力量从哪里来、落在哪里？观众是否能在单帧读出姿态和朝向？每次攻击是否改变空间或关系？若只是连续特效，加入明确的起势、接触、反作用和结果。

## 输入 Brief

收集角色轮廓、服装/武器授权、身高比例、能力限制、场地尺寸、速度级别、镜头比例、目标帧率、对白、音效、血腥边界和参考素材。建立“能力账本”：能做什么、代价是什么、当前是否可用，防止能力无成本升级。

## 五阶段产物

### 1. 角色与姿态库

为每个角色定义三视图锚点、主色块、重心习惯、站姿、受击姿态和表情极值。制作关键姿态清单：预备、发力、接触、失衡、恢复。动作前后轮廓必须可区分，避免两人剪影混在一起。

### 2. 空间与力量路径

画出场地平面图、角色进入/退出方向、镜头轴线、遮挡物和高度层。为每次动作写力量向量、落点、反作用和可见结果；飞行或瞬移也要给出起点、终点和中间参照。重大方向改变用视线或声音先提示。

### 3. 战斗 Treatment 与节奏

采用“观察—试探—升级—代价—选择”的节拍，而非无尽连招。给每次升级分配镜头预算：慢镜只用于关键决策，快速剪辑用于位移和反应。让环境受力（尘土、碎片、衣摆、地面裂纹）证明动作，而不是堆叠发光特效。

### 4. Key pose 与 Shot card

每镜填写时间码、姿态编号、重心、动作阶段、相对距离、摄像机运动、透视强度、特效层、声音、剪辑点和连续性锚点。先做关键姿态帧，再补中间帧；相机旋转必须服务于力量方向。字幕与 Logo 后期叠加。

### 5. 生成与复盘

先验证双方站位、接触帧和结果帧，再生成连贯动作。逐镜检查角色身份、肢体数量、手指、服装纹理、轴线、力量方向、环境反应和血腥等级。错误只重做对应阶段，不让模型“自动加招”。

## 典型故障与修复

- **动作像随机挥舞**：补充动作目的和力量向量，删除没有结果的连招。
- **角色换脸换服**：使用三视图和主色块参考，先锁定关键姿态。
- **空间方向反复翻转**：固定镜头轴线，只有在明确越轴镜或声音过桥后改变方向。
- **特效遮住姿态**：先输出无特效关键帧，再分层添加粒子、光和尘土。
- **速度没有重量**：增加预备、接触停顿、反作用和落地形变。
- **血腥超出边界**：将伤害结果改为碎片、呼吸和失衡等非图形化反应，并确认年龄分级。

## 导演交付格式

1. **方向判断**：动画媒介、动作目的、速度和安全边界。
2. **Brief/能力账本**：角色授权、能力限制和待确认事实。
3. **角色/空间锁**：轮廓、主色、轴线、入口出口和高度层。
4. **Treatment**：升级阶梯、代价、情绪转折和结尾姿态。
5. **动作节拍表**：起势、接触、反作用、结果、声音和剪辑点。
6. **Key pose/Shot card**：姿态编号、重心、镜头、特效层和回退方案。
7. **生成计划**：先关键帧后中间帧，锁定变量与确认点。
8. **复盘记录**：身份、空间、物理、节奏、特效、文字和分级检查。

## 最小示例

输入：两名原创角色在狭窄车站争夺一枚发光徽章。处理：先用站位和视线明确谁持有徽章；第一次抢夺只改变重心，第二次利用柱子遮挡完成换手，最后让警报灯和脚步声迫使双方停战。发光效果不遮住手部接触帧。

## 质量门与安全

通过条件：每次动作有目的、路径和结果；关键姿态单帧可读；角色和轴线连续；环境反应支持重量；特效分层；内容符合年龄分级。不得提供现实武器改造、伤害技巧或针对真人的暴力复刻；后端负责审核、计费和交付。
