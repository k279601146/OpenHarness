# 手账拼贴风小红书图文 Skill

把文字和用户图片，或文字和 AI 示意配图，制作成固定九页的手账风图文。先确认九宫格与文字，再分别生成 9 张独立图片。

适合生活记录、旅行、探店、兴趣爱好、轻量干货、好物推荐、情绪文案和工作与个人经验。真实人物、地点、体验、商品或数据只使用用户提供或已核实的信息。

## 使用

安装合集中的 `vane-xhs-design` 后，在具有图片生成及图片参考能力的会话中选择手账拼贴风，例如：

> 使用手账拼贴风图文 Skill，把以下文字做成九页小红书笔记。我选择文字＋AI 配图：……

也可以选择“文字＋用户图片”，并同时提供照片、截图或产品图。不同客户端的安装位置和图片工具能力不同，以客户端实际说明为准；没有图片生成能力时，本 Skill 无法单独产生图片。

建议先检查预览和逐页文字；用户确认后才生成独立成图。生成结果需逐字核对，3:4 比例以实际输出尺寸为准。预览不能替代高清原图。

本目录中的两张参考图用于固定视觉风格与九页布局；分享本目录前，应确认素材的使用和再分发权限。
