# 内容选择与九页骨架

## 内容选择

先基于用户文字推荐类型，生图前让用户选择或确认；用户已明确类型或授权自主选择则直接使用。类别是叙事辅助，不替换九格位置：

| 类型 | 适合输入 | 内容处理 |
| --- | --- | --- |
| 生活记录 | 一天的片段、日记、居家 | 以用户的时间、场景和感受组织，不虚构经历。 |
| 旅行 | 风景、路线、行程、感受 | 地点、路线、价格和经历仅使用用户提供或已核实的资料。 |
| 探店 | 环境、产品、体验、到店信息 | 店名、地址、价格、营业时间和体验不得自行编造。 |
| 兴趣爱好 | 植物、阅读、摄影、手工 | 分离观察、动作和心得，不把示意图伪称实拍。 |
| 轻量干货 | 几条知识或具体做法 | 每页只承载可读的一个重点；保留使用条件。 |
| 好物推荐 | 产品特征、选择和个人体验 | 用用户提供的产品资料；不杜撰使用效果、对比和评价。 |
| 情绪文案 | 具体感受、处境、片段 | 不强加鸡汤、转折或不存在的个人故事。 |
| 工作与个人经验 | 方法、复盘、场景和感想 | 不虚构业绩、数据、案例或专业判断。 |

长篇技术材料、密集表格或需要严格呈现全部条件的内容不宜强行压缩。解释限制并讨论保留重点或补充材料；默认仍按用户选择提供预览，不自行编造数据。固定 9 页不代表每页都必须有相同文字量。第 7 页不足四项可把同一已给事实按真实子方面组织，或保留部分空白；绝不编造内容。

## 固定对应

按 `assets/approved-plant-reference.png` 的原始 3×3 位置匹配，参考 `assets/layout-skeleton.png` 的位置示意。以下是位置结构，不是必须逐字写入的页面标题：

1. **左上／封面**：上方粗白大字；中部略倾斜的打开式纸本，放两个或几个主题物件／图片；周围小标签；底部右侧红色说明纸，层叠在牛皮纸与小黄纸上。
2. **上中／导读**：左上两行白色标题；右上斜放清单纸；左中红色圆章；下方竖向浅色正文纸承载若干短段，黄色标签横跨纸张上沿。标题、清单、正文各有层级。
3. **右上／双卡 A**：上下两张横向白纸。上卡文字在左、照片叠放在右；下卡照片在左、文字在右。保留小标签、纸夹和露出的红色圆形。
4. **左中／图片拼贴**：大张倾斜赭黄色纸作底，四张不同大小、轻微错位的图片；标题纸条横跨中间，少量图钉、圆章和剪贴图。需要四个视觉位置，但不能虚构四张真实照片。
5. **正中／双卡＋深色文字块**：上卡左文右图；下卡在米白底纸上叠深牛皮纸内容块，搭配简短标题和正文。保留角落小图与回形针。
6. **右中／双卡 B**：两张错开的横纸；上卡左文右侧叠两张图片，下卡左侧叠图、右侧文字，保留小标签和背后的红色半圆。
7. **左下／重点四条**：上方标题及短引言；下方四张各自独立、略有错位与倾斜的横向白纸条。参考植物版，照片位置按右、左、右、左交替；每条是小标题与约一至两行说明，加对应小图、纸孔与夹子。图片数量受用户素材限制时可重用、局部裁切真实素材并保持含义；内容不足则留白，不能捏造。不要简化成等宽 UI 表格或一张大图。
8. **下中／双卡 C**：上下两张横向白纸，上卡左文右图，下卡左图右文，照片纸轻微倾斜并互相压叠；保留图钉、回形针、红色圆形。
9. **右下／内容＋收束**：上卡左文右侧两图；下卡白纸叠深色牛皮纸，放总结和自然的关注／收藏引导，小主题剪贴图位于右下。用户不希望引导时自然收尾。

页面元素保留其占位结构，但各页面的文案作用应依据用户原文，不把参考中的招募、品牌、地址或特定题材作为默认内容。参考图所展示的是用户认可的设计，不保证生成器能逐像素复刻。
