# Vane 小红书图文设计

根据用户提供的内容制作小红书图文，保留用户指定的素材、页数、比例和交付方式；不虚构个人经历、产品效果、地点或其他事实。实际生成图片时使用可用的图像生成或编辑工具，不把文字方案或预览冒充成图。

## 风格选择

- **手帐拼贴风（也称手账拼贴风）**：适合生活记录、兴趣分享、旅行、探店、好物和轻量干货。读取 [手帐拼贴风制作指南](styles/scrapbook/STYLE.md)，并按该文件所在目录解析其引用的素材与参考文档；遵循其中的素材选择、九页布局、预览与文字确认、独立生成和验收流程。
- **极简产品风**：适合产品、AI 工具、食品、家居、生活方式和简短观点，以白底、留白和统一视觉主体为特点。读取 [极简产品风制作指南](styles/minimal-product/STYLE.md)，并按该文件所在目录解析其引用的素材与参考文档；遵循其中的主体选择、九页布局、预览与文字确认、独立生成和验收流程。
- **撞色大字风**：适合活动宣传、创作灵感、潮流内容、品牌故事和短步骤教程，以高对比色块和醒目大字为特点。读取 [撞色大字风制作指南](styles/bold-color/STYLE.md)，并按该文件所在目录解析其引用的素材与参考文档；遵循其中的配图选择、九页布局、预览与文字确认、独立生成和验收流程。
- 用户没有指定风格时，可根据内容推荐或请用户选择；用户明确提出其他风格时尊重其要求，不要声称该风格已经内置，也不要强行套用已收录的模板。

按用户明确要求交付规划、预览或独立图片。三种风格的九宫格都是预览而不是九张高清原图；生成独立成图前，遵循所选风格指南中对预览与文字的确认要求。生成及修改文字、真实照片、图片比例和可读性时，以实际工具结果为准；不要擅自发布。
