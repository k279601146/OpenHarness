# Technical and Process Visuals

Use verified product information to create explanatory drawings, tech-pack visuals or process graphics. Determine whether the user needs a conceptual illustration or a precise production document; do not present the former as the latter.

- For product drawings, use supplied views and measurements. Keep view labels and dimension endpoints consistent. Do not invent rear construction, seams, internal components or tolerances.
- For an exploded view, require component evidence. If unavailable, offer an external feature diagram or clearly scoped concept instead of asserting hidden structure.
- For a process, preserve the supplied sequence, branches and relationships. A visual reference can guide layout, not add manufacturing steps or certifications.
- Choose image generation for an illustrative result and native diagrams/typography when exact labels, connections or revision matter. Combine them when useful.

Use the requested output language and retain technical identifiers. Inspect arrow direction, label-to-part relationships, counts and units, as well as visual quality. An attractive diagram with incorrect relationships fails the task.
