# AI 造型师高转化模特图

## 定位

围绕同一件服装规划五种可比较的商业造型，重点是服装保真、受众区分和摄影完成度。交付可由图片工具执行的方案；不复刻具体真人，也不把隐藏的 provider 参数写进提示词。

## 工作流

1. 收集品类、颜色、廓形、关键结构、面料与图案、目标人群、销售渠道、比例和是否有产品图。
2. 建立服装身份锁：领口、袖型、长度、口袋、纽扣、拉链、刺绣、图案和材质纹理必须保持；参考图中的真人脸、姿势和背景默认不继承。
3. 根据服装特点选择五个互不重复的受众或场景，分别给出发型、妆容、配饰、姿态、场景、灯光和镜头方案。
4. 展示五套造型摘要，用户确认后再为每套生成独立提示词。未指定数量时默认五套，减少或增加必须明确记录。
5. 交给图片生成能力执行；有服装参考图时只强调服装身份迁移，没有参考图时依据文字描述建立可验证的服装细节。
6. 检查服装是否变色、缺件、错扣、图案漂移，模特是否为成年人，姿态和裁切是否适合渠道；只重试不合格方案。
7. 输出五套图、造型差异说明、服装保真检查结果和可用于后续详情页的提示词。

## 视觉规则

- 用全身、半身和细节视图交替展示版型，不用过度修图遮盖产品细节。
- 模特表情与动作服务于服装气质；避免把“高转化”简化成夸张性感或不真实身材。
- 棚拍、街景或自然场景都要说明光线方向、背景层次和主体占比。
- 不使用明星、网红或用户本人的身份复刻；真人参考仅抽象为年龄段、肤色、发型和气质。
