# 建筑空间导演

## 何时使用

适用于建筑竞标、地产展示、室内设计、酒店、展馆和公共空间的宣传或概念可视化。真实项目与概念方案必须分开标记；不把效果图当作施工、面积或配套承诺。

## 空间诊断

空间片要回答：从哪里进入、如何移动、核心空间是什么、光线何时改变、人在其中做什么。先决定观众的参观路线，再决定镜头和音乐。

## 输入 Brief

收集平面图/模型/照片、尺寸、层高、入口、功能分区、朝向、材质、采光、设施事实、景观授权、受众、时长和比例。

## 五阶段工作流

### 1. 空间身份锁

记录入口、核心节点、层高、门窗、固定家具、材质、结构柱、视线轴线和不可改变的功能。用平面图建立镜头站位与路线。

### 2. 功能与情绪

建立空间节点表：节点功能、用户行为、光线状态、材质证据和叙事作用。选择“归家、工作、休憩、交流、穿行或展示”中的主体验。

### 3. 参观 Treatment

组织“入口建立—主空间—细节节点—人与空间互动—日夜/季节变化—定位收束”。明确哪些镜头是实景、哪些是概念重建，避免无限制的虚构景观。

### 4. Shot 与动线

镜头卡包含时间码、站位、景别、移动方向、镜头高度、材质/采光、人物尺度、环境声、转场和空间锚点。广角服务路线，细节服务材质，不用不可能的广角扭曲空间。

### 5. 生成与复盘

确认面积、设施、视野和景观事实后交给图片/视频能力。生成后检查比例、门窗、家具数量、动线、光照、窗外景观和字幕；将价格/面积等精确信息后期叠加。

## 典型故障与修复

- **空间越拍越大**：锁定层高、门宽和家具作为尺度参照。
- **路线无法追踪**：回到平面图，减少跳跃镜头并增加过渡。
- **家具/门窗漂移**：把固定物件纳入身份锁，逐镜对照。
- **效果图被误认为承诺**：加入概念标识和事实说明。
- **画面只有空房间**：安排真实的使用行为，但不泄露私人信息。

## 导演交付格式

每次执行都按下面的顺序组织结果，避免只输出一段形容词：

1. **方向判断**：说明为什么属于本技能、主类型、观众承诺、时长与不适用边界。
2. **Brief 摘要**：列出已确认事实、用户授权素材、待核查信息、可撤回假设和需要用户确认的决策。
3. **资产锁**：记录角色/产品/地点/道具/声音的不可变字段、可变字段、版本号和跨镜头锚点。
4. **Treatment**：用一句话 Logline、情绪曲线、信息释放顺序、声音母题、镜头预算和结尾画面说明导演意图。
5. **节拍表**：为每个时间段写目标、冲突或卖点、画面证据、表演动作、声音和剪辑目的。
6. **Shot card**：每镜必须写时间码、景别/视角、主体位置、动作阶段、摄影机运动、光线/材质、声音、字幕意图、连续性锚点和失败回退方案。
7. **生成计划**：说明先做哪些关键帧或预演、候选数量、哪些变量保持不变、何时暂停让用户确认；不自行扩大输出数量。
8. **复盘记录**：逐项记录身份、空间、动作、节奏、声音、文字和安全检查结果；重试只修改已定位的问题。

默认先交付 draft，用户确认后才进入媒体生成。技能只提供判断、编排和验收，不写 provider 字段、密钥、地址、计费请求或宿主机路径。

## 最小示例

输入：小户型改造要展示收纳、采光和动线。
导演决策：用同一镜头轴从入口走到窗边，家具作为尺度参照。
节拍示例：入口建立 → 收纳展开 → 工作/休息切换 → 午后光线 → 平面定位。

## 质量门与边界

通过条件：动线可追踪；比例可信；功能和设施有来源；实景/概念有标注；人物只作为尺度和生活证明。不泄露住户隐私、门禁、安防盲区或精确私人地址，不虚构产权、面积、学区、价格和政府背书。
