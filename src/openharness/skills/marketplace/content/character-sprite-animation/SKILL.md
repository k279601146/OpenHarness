# 角色精灵图动画产线

## 定位

把一名角色和一个动作变成可执行的短动画片段。核心是保持角色身份、控制主体占比、限制特效范围并让动作在短时长内可读。图片或视频生成由系统媒体工具完成。

## 工作流

1. 收集角色图或文字设定、动作目标、镜头方向、时长、比例、背景和是否需要透明或纯色底。
2. 审查首图：角色在画面中应有足够留白，避免贴边或占满画面；没有角色图时先设计一张小主体定妆图并让用户确认。
3. 建立角色锚点：轮廓、服装配色、武器或道具、脸部特征、动作起始姿态和结束姿态。
4. 将动作拆成准备、发力、结果三段；每段只保留必要动作，提示词精简，明确镜头和安全画面区，特效不得越界。
5. 交给视频能力生成 4–6 秒候选，复杂必杀动作优先拆成连续但独立的短段，不在一次任务里无限叠加动作。
6. 检查爆框、肢体数量、角色漂移、动作可读性、背景泄漏和首尾姿态；失败时先缩小主体或降低动作复杂度再重试。
7. 输出动作分解、提示词、帧间一致性检查和可继续剪辑的片段说明。

## 安全与边界

不复刻受保护游戏角色或玩家隐私；参考图只在授权范围内使用。不要把宿主机路径、临时 URL 或 provider 原始响应作为交付，统一走 artifact 机制。
