# AI 视觉导演路由

## 路由表

- 故事、小说、剧本到视频包 → 故事与结构
- 角色外观、表情、服装、一致性 → 角色设计
- 空间、建筑、光照、材质、地理关系 → 场景/世界观美术
- 故事板、分镜、镜头预算 → 故事板与分镜
- 独立海报、封面、营销视觉 → 海报与平面
- 参考图风格提取、融合和迁移 → 风格资产
- 首尾帧、动作、连续片段 → 视频提示词与动效

## 主控流程

1. 读取用户意图、素材、受众、平台、比例、时长、数量和授权边界。只有缺少会改变路由的选择时才追问。
2. 选择一个主路由和必要的辅助路由，说明它们的交付关系；不同时维护多套互相冲突的字段协议。
3. 先生成 draft：包括创意方向、资产依赖、镜头/画面预算、风险点和待确认项。用户未确认时不写入项目锁定状态。
4. 用户确认后，按依赖顺序执行：角色/场景锚点 → 故事板或画面方案 → 图片/视频生成 → 质检 → artifact 交付。
5. 每一步记录版本和输入输出关系；修改时创建新 draft，不覆盖已锁定的资产。
6. 生成后检查风格、角色、场景、时长、比例、素材引用和内容安全，失败时返回具体阶段与可行动修复。

## 状态与边界

建议状态为 draft → locked → committed。路由技能只做判断、编排和验收，不读取 provider 密钥、不选择隐藏上游、不直接执行计费调用；后端负责权限、reservation、安全出站、结果校验和 artifact 注册。

复杂项目应拆分为可回顾的阶段，避免一次提示词同时承担角色设定、空间设计、镜头调度和最终渲染的全部责任。
