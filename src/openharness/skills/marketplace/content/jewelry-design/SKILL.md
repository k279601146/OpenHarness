# 珠宝设计出款

## 适用范围

面向原创珠宝概念和可制造性思考：单款精品、系列设计、参考风格延展、材质或宝石替换、批量候选。用户已经选定款式并要求九图、详情页、文案或投放视频时，交给电商或视频技能。

## 工作流

1. 收集珠宝品类、佩戴对象、使用场景、预算或工艺边界、数量、金属与宝石偏好，以及可使用的草图或参考素材。
2. 建立“身份锁”：主结构、比例、连接方式、佩戴关系、宝石数量与位置、表面工艺和必须保留的识别点。
3. 形成设计矩阵。每个 design_id 对应一套明确的轮廓、结构、材质、色彩和主题变化；用户要 N 款就创建 N 个编号，不用一个提示词代替多款。
4. 先给出矩阵摘要和一到两个示例方案确认，确认后再提交图片生成。批量任务可分批执行，但不改变已确认的编号与数量。
5. 生成主视图和必要的结构补充视图，统一背景、尺度参照和光线以便比较。
6. 按结构、比例、宝石镶嵌、金属质感、佩戴合理性和系列一致性检查；失败只重试对应编号。
7. 交付设计图、设计说明、材质与工艺假设、编号清单和后续打样建议。

## 设计判断

- 先保证受力、连接、开合和佩戴逻辑，再追求装饰复杂度。
- 用轮廓和负空间建立辨识度；不要只堆叠宝石、纹样或品牌符号。
- 参考图只提取可泛化的比例、材质和工艺语言，不复刻他人独特款式、Logo 或签名。
- 高级珠宝需要说明主石、配石、镶嵌方式和金属色之间的关系；不确定的尺寸标为估算。
- 批量方案要有清晰差异，但保持同一系列的家族特征。

## 质量门与安全

- 编号数量、输出数量和用户确认一致，超量时停止并请求确认。
- 图中结构不能出现明显断裂、漂浮、穿模或无法佩戴的连接。
- 不把图片中的真人身份、珠宝品牌标识或私人信息带入新设计。
- 生成与交付由后端媒体和 artifact 能力完成；技能不读取密钥、不直接访问第三方 provider。
