# 广告视觉提示词指南

## SLCT 结构

- **Subject**：主体、数量、位置、动作和卖点证据。
- **Lighting/Look**：光源方向、色温、材质表现、风格和真实程度。
- **Camera**：景别、角度、运动、焦点、节奏和设备视角。
- **Technical**：比例、时长、语言、字幕安全区、输出数量和用途。

## 工作流

1. 收集产品事实、目标受众、渠道、核心卖点、证据素材、CTA、比例、时长和禁用承诺。没有真实卖点时先澄清，不凭空编造功效。
2. 选择广告形态：产品静物/材质 B-roll、UGC 开箱、口播体验、问题—证明—结果、品牌氛围片或多变体测试。
3. 用 SLCT 写一个最小可执行场景；每场不超过三个主要实体，明确左右/前后关系和动作因果。
4. 处理常见幻觉：产品标签和 Logo 采用后期叠加；复杂手部交互拆镜头；多人对话减少到可控数量；物理效果写出起点、作用力和结果。
5. 先给出 2–3 个创意方向和预算/数量假设，用户确认后再交给图片或视频能力生成。每个变体都有独立编号。
6. 按 pass³ 质检：**Proof** 卖点是否可见，**Pacing** 前几秒是否抓住注意力，**Platform** 比例、时长、字幕和 CTA 是否符合渠道。只重试失败变体。

## 交付与边界

输出 brief、SLCT 提示词、镜头序列、负向约束、变体差异和质检结果。不得虚构测评、医疗/金融功效、品牌授权或消费者反馈；真实素材和生成结果由后端安全与 artifact 机制管理。
