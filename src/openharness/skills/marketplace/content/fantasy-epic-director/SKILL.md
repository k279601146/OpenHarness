# 奇幻史诗导演

## 何时使用

适用于神话世界、魔法冒险、古文明、英雄抉择、游戏世界观和史诗品牌片。单张角色/场景设定图转交角色或世界观美术技能；完整长剧本先交剧本技能。本技能负责导演化短片方案与可执行镜头，不承担后端媒体调用。

## 导演诊断

先回答：

1. 奇观改变了谁的目标或风险？
2. 魔法/神话规则的触发、限制和代价是什么？
3. 观众先知道哪条传说，角色再发现哪条证据？
4. 哪个道具、动作或环境反应能让世界观可信？

把“像某某奇幻电影”拆成仪式构图、材质、色彩、节奏、声音和空间尺度，不复制具体作品的角色、地图、服饰或镜头。

## 输入 Brief

收集世界时代、地理、法则、角色使命、盟友/对手、关键遗物、族群关系、文化来源、时长、比例、受众、对白、参考素材和不可使用元素。真实神话与历史素材要标明来源、改编范围和不确定信息。

## 五阶段工作流

### 1. 世界与法则

建立世界宪法：核心法则、资源/权力、魔法触发、代价、禁忌、社会后果。为每条法则指定至少一个视觉证据，例如光线变化、伤痕、环境反应或道具状态。

### 2. 角色与遗物

建立角色卡：外形轮廓、服装层次、动作习惯、愿望、恐惧和不可背叛的底线。为遗物记录形状、材质、持有者、状态变体和剧情功能，防止跨镜头漂移。

### 3. 叙事 Treatment

从“启程、召唤、仪式、决战前夜、代价选择”中选一个主结构。写出 Logline、情绪曲线、信息释放顺序、声音母题和最终画面；每个奇观都必须推动一个决定。

### 4. Shot 与运动

镜头卡包含时间码、景别、构图、走位、动作、魔法反应、摄影机运动、光线、声音、连续性锚点和剪辑目的。远景负责尺度，中景负责关系，近景负责代价与选择；控制同一镜头的生物、粒子和动作数量。

### 5. 生成与复盘

先让用户确认世界规则、文化边界、角色/遗物锁和结尾语气，再交给图片或视频能力。生成后检查法则、材质、比例、动作受力、服饰和光线；按镜头定位问题，不整段推翻。

## 典型故障与修复

- **只有城堡和粒子**：补角色目标、规则证据和代价。
- **魔法没有重量**：增加施法准备、阻力、光影遮挡和结果反馈。
- **跨镜头角色变形**：缩减服装细节，固定轮廓、主色和标志道具。
- **文化符号混杂**：拆分来源，选一个主文化语境，标出创作性融合。
- **预告像设定图合集**：给每镜安排信息升级和声音过桥。

## 导演交付格式

每次执行都按下面的顺序组织结果，避免只输出一段形容词：

1. **方向判断**：说明为什么属于本技能、主类型、观众承诺、时长与不适用边界。
2. **Brief 摘要**：列出已确认事实、用户授权素材、待核查信息、可撤回假设和需要用户确认的决策。
3. **资产锁**：记录角色/产品/地点/道具/声音的不可变字段、可变字段、版本号和跨镜头锚点。
4. **Treatment**：用一句话 Logline、情绪曲线、信息释放顺序、声音母题、镜头预算和结尾画面说明导演意图。
5. **节拍表**：为每个时间段写目标、冲突或卖点、画面证据、表演动作、声音和剪辑目的。
6. **Shot card**：每镜必须写时间码、景别/视角、主体位置、动作阶段、摄影机运动、光线/材质、声音、字幕意图、连续性锚点和失败回退方案。
7. **生成计划**：说明先做哪些关键帧或预演、候选数量、哪些变量保持不变、何时暂停让用户确认；不自行扩大输出数量。
8. **复盘记录**：逐项记录身份、空间、动作、节奏、声音、文字和安全检查结果；重试只修改已定位的问题。

默认先交付 draft，用户确认后才进入媒体生成。技能只提供判断、编排和验收，不写 provider 字段、密钥、地址、计费请求或宿主机路径。

## 最小示例

输入：守门人只能用一次火焰唤醒沉睡的河流。
导演决策：先展示法则和代价，再让奇观改变队伍关系。
节拍示例：遗物裂纹 → 仪式准备 → 火焰点燃 → 河流苏醒 → 守门人失去记忆。

## 质量门与边界

通过条件：世界规则可见；角色有选择和代价；遗物/服饰连续；奇观服务剧情；原创边界清晰。不得把宗教符号、现实民族或受保护作品当作可复制装饰。后端负责审核、计费、路由和 artifact 交付。
