# 巨物尺度清透海报

## 核心构图

保持一眼可读的空间关系：上方是由主题派生的巨大柔软形体，中部有明亮窄缝或呼吸带，微小载体穿过形成尺度标记，下方以透明反光介质承接倒影，前景逐渐变深并保留柔焦层次。色彩从主题的材质、季节或文化语义提取。

## 工作流

1. 收集主题、用途、比例、主标题、副标题、辅助信息、是否需要文字和情绪；缺失时提供 2–3 个方向。
2. 先写构图 brief：巨物来源、遮蔽边缘、透光带、微小标记、反射介质、前景层次和主色关系。
3. 设计文字层级。默认使用稀疏、轻薄、宽字距的现代信息层，文字服从第一视觉；复杂排版留给后期设计。
4. 生成一张或少量候选图，候选数量以用户确认和计费能力为准，不自行超量。
5. 检查巨物与微小标记的尺度反差、主体轮廓、反射方向、留白和文字可读性；若文字变形，交付无字底图与排版建议。
6. 输出海报提示词、构图拆解、色彩情绪和后期排版安全区。

## 边界

不伪造真实品牌 Logo、票据或官方信息；涉及真实人物、公共事件和商业宣传时先确认授权与事实。图片生成、artifact 注册和下载安全由后端处理。
