# 时尚走秀短视频导演

## 输入与边界

至少需要模特特征、服装特征和场景。缺少任一项先追问；用户只要图片时转交服装图技能。该技能负责导演意图、镜头序列和可执行提示词，不调用 provider 或拼接视频 API 请求。

## 15 秒分镜结构

1. **Hook（1–3 镜）**：拉链、面料、鞋跟、眼神或建筑线条的局部特写，快速建立材质与气场。
2. **Power Walk（4–7 镜）**：半身到全身的跟拍、侧跟和低机位，展示服装廓形与步态。
3. **Detail（8–10 镜）**：微距交替展示五金、皮革反光、褶皱、缝线和动态飘动。
4. **Environment（11–13 镜）**：让模特与城市或建筑几何产生关系，保持动线连续。
5. **Brand beat（14–15 镜）**：英雄定格、品牌信息或行动召唤，留出可读安全区。

## 编排规则

- 15 秒通常 12–15 镜，每镜约 0.8–1.5 秒；节奏由动作复杂度和平台要求调整。
- 全景与特写必须交替，跟拍方向、轴线和模特视线保持连续。
- 至少设计一种逆光或缝隙漏光、一种强调面料的侧光；不要只写“高级光影”。
- 每个镜头写清景别、视角、主体动作、摄影机运动、光线、声音或字幕意图。
- 同一条成片应是一组 Shot 序列，不把每个镜头误当作独立视频任务。

## 验收

镜头在前 3 秒有可感知的视觉钩子；服装身份在中段和细节镜头持续可辨；模特动作安全自然；字幕或 Logo 不遮挡主体且不伪造真实品牌。输出时间轴分镜表、每镜提示词、镜头连续性说明和可选配乐方向。
