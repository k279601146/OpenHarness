# GPT Image 2.5 电商提示词与工作流手册 (Prompt Cookbook)

本技能是将 GPT Image 2.5 在电商全生命周期中的实际生产需求工程化沉淀的**提示词与工作流案例库（Prompt Cookbook）**。它将电商图片制作拆解为标准化、可直接复用的 Prompt 模板、输入配置与案例配方，帮助卖家与创作者在不重新拍摄、不破坏商品真实性的前提下，高保真完成全球电商视觉生产。

---

## 核心价值与能力边界

1. **配方即用（Recipe-Based）**：
   每一个场景均对应「输入原图标准 + 即用 Prompt 模板 + 关键占位符说明 + 真实案例结构」，将自然语言需求精准映射为 GPT Image 2.5 的有效调度。
2. **商品一致性锁（Product Identity Lock）**：
   严格守护电商红线——商品本身的形状、材质、Logo、商标、标签文字、物理比例绝不漂移变形；替换的仅是场景、模特、光影或局部属性。
3. **分层深入（Modular References）**：
   本手册包含完整的电商场景大类。遇到具体任务时，Agent 根据场景决策树调取 `references/` 下的详尽案例集与 Prompt 配方。

---

## 商品一致性保护守则 (Product Identity Lock)

电商图片不同于纯艺术创作，**合规与真实**是生命线。在生成与润色任何电商提示词时，必须强制包含以下约束：

- **Preserve Form & Identity**：保留商品的原生外形、比例、轮廓、按键、接口与几何结构，严禁擅自重新设计（No redesign）。
- **Label & Logo Integrity**：原包装上的品牌 Logo、产品名称、规格参数文本必须保持原样清晰，不得涂抹、重绘或替换为虚假信息。
- **Material Fidelity**：正确还原金属拉丝、磨砂塑料、透明玻璃、液体折射、皮革纹理等真实物理质感。
- **Natural Integration**：新场景的环境光照（Directional lighting、Color temperature）与地面/台面接触阴影（Contact shadow、Ambient occlusion）必须自然贴合，杜绝“浮空感”。
- **No Hallucinated Claims**：严禁在生成的图文上虚构医疗功效、虚假认证标识（如未经许可的 FDA/CE/ISO）或虚假评分好评。

## 六阶段标准化执行工作流

当用户提出电商作图需求时，Agent 应遵循以下六步闭环流程：

1. **输入审视与资产核验**：
   - 检查用户提供的商品原图（是否为白底图、实拍图或模特图）。
   - 明确目标商品品类、核心卖点、目标销售平台、目标国家与语言。
2. **场景分类与配方匹配**：
   - 从决策树中匹配最贴切的案例（如需要主图套图则匹配主图套图；需要换模特则匹配指定模特替换）。
   - 查阅 `references/` 中对应章节的 Prompt 原文。
3. **参数装配与占位符填充**：
   - 将用户提供的事实性信息填入 Prompt 模板中。
   - 注入强制性的商品一致性锁语句（如 `Keep the product itself unchanged: preserve exact shape, proportions, packaging, logo, and label text`）。
4. **生成交付与质量门质检 (Pass³ Checklist)**：
   - **Proof**：核心卖点（材质、尺寸、防水、吸力、包装）是否清晰可见、可直观感知？
   - **Precision**：商品本身是否 100% 还原？文字标签是否出现乱码或多余构件？
   - **Platform**：构图比例（1:1、3:4、4:5、16:9）、排版安全区与留白是否符合目标平台规则？
5. **多语言与本地化核对**：
   - 多语言文字语法是否地道？排版是否发生重叠截断？
6. **迭代与变体拓展**：
   - 若需拓展模特姿势、切换材质或生成全套 7 屏主图，沿用对应案例配方进行批次生产。
