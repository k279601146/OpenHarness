# 画风与生图提示词

下面的提示词用于生成每一幕的彩色母图。它只负责静帧质量，不负责动画；线稿显现、颜色推进、字幕叠加和成片渲染由 SaaS 后端 Tool 完成。

先阅读 `styles.md`，为全片锁定一种风格。每幕提示词应由“所选风格段 + 通用约束段 + 每幕变量段 + 负面约束”组成。不要把完整工具请求写进提示词。

## 通用约束段

把这一段放在每一幕提示词的开头，并按 `styles.md` 替换具体风格语汇：

```text
手绘故事插画，完整 3:4 竖屏彩色静帧，适合 720x960 成片；使用已锁定的【风格名称】风格，线条、留白、纸面质感和上色方式必须全片一致；画面有足够清楚的轮廓线和内部结构线，便于后端从同一张彩色母图提取线稿；大面积纯白纸面留白，上方保留干净字幕安全区，不生成故事字幕；主体主要位于画面下方 45%-55%，人物头部和关键道具不能顶入字幕安全区；背景只保留一到两个有用的环境锚点；生活化、安静、克制，具有可见的叙事因果；人物、手、腿、鞋子、衣服边缘完整清楚；完整彩色母图，非黑白草图，非海报排版，非照片。
```

H 是通用组合画风，不等于成语主题。成语主题使用 H 风格时，允许在上述约束上增加一个画面题款例外：负空间合适位置用行书或近似行书笔意撰写 `{成语}`，题款小而清楚，不遮挡主体和顶部字幕安全区；除此之外仍不生成故事字幕、解释正文或封面标题。

## 每幕变量段

把下面的占位内容替换成当前分镜信息，放在通用约束段和风格段之后：

```text
第{幕号}幕，{地点和时间}。
在场人物：{人物1}、{人物2}。
关键动作：{一个明确的动作或反应}。
关键道具：{一个推动情节的道具}。
环境细节：{最多两个背景锚点}。
景别和构图：{远景 / 中景 / 近景 / 道具特写}，动作方向从左向右或符合故事推进方向。
情绪结果：{这一幕结束时观众能看见的变化}。
```

## 风格段接入

把 `styles.md` 中选定风格压缩成每幕提示词的短风格段：

- A：粗黑涂色线稿、儿童蜡笔露白、局部越线、纯白纸。
- B：靛蓝钢笔轻速写、大面积留白、唯一橙色情绪焦点。
- C：北欧水粉绘本、限定蓝黄珊瑚色、哑光干刷、大留白。
- D：粗黑朴拙线稿、低饱和不超过 4 色、橙红单点强调。
- F：软边缘水彩、低饱和马卡龙暖色、柔和治愈。
- G：黑白线稿为主、少量淡蜡笔、至少 60% 白色留白。
- H：极简线条/简笔画、水墨淡染、蔡志忠漫画式国风哲理幽默、大留白轻喜剧构图。

全片风格段必须一致，只替换每幕的地点、动作、人物关系和道具。

## 负面提示词

如果供应商没有负面提示词字段，就直接接在主提示词末尾：

```text
不要照片写实，不要3D渲染，不要动漫厚涂，不要鲜艳霓虹色，不要高饱和渐变，不要复杂建筑，不要人群，不要密集背景，不要满屏雨线，不要大面积纯黑，不要风格混用，不要白色边框，不要白色圆形地面，不要裁掉腿和鞋子，不要缺失手指，不要缺衣服，不要人物漂浮，不要故事字幕，不要水印，不要 logo，不要分镜拼贴，不要重复人物，不要从上到下出现的动作构图。非成语主题不要封面标题；成语主题只允许一处行书成语题款，不要解释性正文。
```

## 参考图锁定角色

使用参考图编辑时，在变量段前加入：

```text
严格参考输入图中的主角外观、发型、服装轮廓、鞋子形状、线条粗细和纸张质感；保持角色身份和画风一致，只改变本幕的地点、动作、道具和人物关系。不要重新设计主角，不要改变年龄、发型、服装主色和身体比例。
```

同一个故事中，可以固定一张角色参考图和一张画风参考图。每幕仍然要生成不同的完整彩色母图，不能用同一张图裁切凑时长。

## 出图验收与重试

生成每张母图后先验收，再进入下一步：

- 画面必须是完整彩色母图，不是草稿、拼贴、海报、裁切截图或局部特写误用。
- 全片风格一致，线条粗细、纸面、上色方式不能漂移。
- 主角外观一致，不能变脸、换年龄、换发型、换服装主色或换身体比例。
- 字幕安全区保持干净，不要把故事正文生成进图里。
- 如果有道具文字，必须短、清晰，并贴合物体透视。
- 成语主题只允许把 `{成语}` 作为一处行书题款放在负空间，不能把含义解释或故事字幕生成进图里。
- 同一故事不能用相同构图、镜像、局部放大或换色当作新幕。
- 背景必须干净，环境锚点少而准，不能因细节过密影响线稿提取。

不合格时重写提示词重生该幕，而不是在后续视频组装时补救。
