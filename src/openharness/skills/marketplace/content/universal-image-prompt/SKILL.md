# 通用图像提示词工程

## 任务分类

- **文生图**：没有参考素材，从概念建立主体和场景。
- **参考图编辑**：保留主体身份、构图或材质，只改变用户指定部分。
- **局部重绘**：先确认区域和遮罩意图，明确“保留什么、替换什么”。
- **多参考合成**：为每张参考图分配角色（主体、服装、场景、色彩），防止内容混融。
- **设计图/海报/UI**：先确定信息层级和后期排版边界，避免让生成模型承担精确文字。

## 工作流

1. 读取用户目标、用途、受众、比例、数量、参考素材和禁用内容；缺少会改变结果的选择时只问一到三个关键问题。
2. 建立不可变清单：主体数量与身份、空间位置、关键材质、品牌或产品事实、必须保留的文字；把可变项单独列出。
3. 按“主体 → 场景与关系 → 光线与色彩 → 镜头与构图 → 材质细节 → 输出约束”的顺序写提示词。每个实体尽量给出数量、位置和动作。
4. 预检幻觉风险：主体不超过三个、避免互相矛盾的形容词、复杂交互拆成多张图、标签文字预留后期叠加。
5. 用户确认方向后交给图片工具执行；输出数量以用户确认和后端 reservation 为准，不自行扩张。
6. 生成后逐项比对身份锁、空间关系、手部/面部、文字可读性、边缘和尺寸；只修正失败变量并重试。

## 参考素材规则

参考图只在用户授权范围内使用。编辑任务必须说明保留事实和允许变化的区域；不从真人照片推断敏感身份，不复刻明星、艺术家签名或受保护角色。真实 Logo、长文本和精确数据优先后期合成。

## 交付

输出任务分类、锁定项、提示词、负向约束、尺寸/比例建议和质检清单。真实图片通过系统 artifact 机制交付，不返回 provider URL、宿主机路径或密钥。
