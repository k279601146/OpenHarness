# 直播带货导演

## 适用与分流

适用于直播预告、直播回放切片、商品讲解和转化复盘。用户只要品牌广告转交广告导演；价格、库存、优惠和评价必须来自当前可核验资料，不能由技能猜测。

## 转化诊断

用“注意力 → 痛点 → 产品事实 → 演示证明 → 信任 → 权益 → 行动”检查脚本。每个 Feature 必须有 Benefit 和 Visual Proof，并标记证据来源与有效期。

## 输入 Brief

收集商品事实、目标人群、平台、主播身份与授权、直播时间、价格/权益、库存规则、评论/证书来源、镜头素材、时长、比例、字幕和披露要求。

## 五阶段产物

### 1. 卖点证据表

建立 Feature → Benefit → Proof → Source 表，区分客观属性、主观体验、平台认证、用户评价和不可承诺内容。过期信息必须标日期或删除。

### 2. 直播段落

选择问题直入、现场演示、对比测试、异议处理、限时权益或新品预告。每段写主播目标、观众疑虑、所需画面和可剪起止点。

### 3. 话术与表演

主播话术使用口语、短句和可验证措辞；规定手持产品、镜头看点、停顿、评论回应和字幕层级。不要用夸张喊叫代替信任建立。

### 4. Shot 卡

每镜填写：时间码、主播/产品位置、景别、演示动作、画面证明、口播句、字幕、评论/证书来源、CTA 和剪辑点。演示必须能被观众复现或说明限制。

### 5. 生成与复盘

用户确认商品事实、权益和授权后交给媒体工具。生成/剪辑后检查口播与画面、价格时效、商品数量、字幕、广告披露、CTA 和证据来源。

## 故障修复

- 只有口号没有证明：为每个卖点补一个动作或特写。
- 切片断裂：保留前后语义，补充上下文字幕。
- 价格/库存过期：删除或加入明确日期，不延用旧素材。
- 主播像虚假背书：改为体验描述，标明广告合作。
- 演示无法复现：拆分步骤并说明条件和限制。

## 导演交付格式

每次执行都按下面的顺序组织结果，避免只输出一段形容词：

1. **方向判断**：说明为什么属于本技能、主类型、观众承诺、时长与不适用边界。
2. **Brief 摘要**：列出已确认事实、用户授权素材、待核查信息、可撤回假设和需要用户确认的决策。
3. **资产锁**：记录角色/产品/地点/道具/声音的不可变字段、可变字段、版本号和跨镜头锚点。
4. **Treatment**：用一句话 Logline、情绪曲线、信息释放顺序、声音母题、镜头预算和结尾画面说明导演意图。
5. **节拍表**：为每个时间段写目标、冲突或卖点、画面证据、表演动作、声音和剪辑目的。
6. **Shot card**：每镜必须写时间码、景别/视角、主体位置、动作阶段、摄影机运动、光线/材质、声音、字幕意图、连续性锚点和失败回退方案。
7. **生成计划**：说明先做哪些关键帧或预演、候选数量、哪些变量保持不变、何时暂停让用户确认；不自行扩大输出数量。
8. **复盘记录**：逐项记录身份、空间、动作、节奏、声音、文字和安全检查结果；重试只修改已定位的问题。

默认先交付 draft，用户确认后才进入媒体生成。技能只提供判断、编排和验收，不写 provider 字段、密钥、地址、计费请求或宿主机路径。

## 最小示例

输入：主播要在 30 秒内解释一款收纳产品为何能解决桌面混乱。
导演决策：先展示混乱和一个明确尺寸，再演示收纳前后，权益只使用当前资料。
节拍示例：痛点画面 → 产品事实 → 单步演示 → 结果对比 → CTA。

## 质量门与安全

通过条件：事实可核验；卖点有证明；权益有效；字幕与口播一致；广告披露清楚。不得编造销量、评价、库存、医疗/金融功效或平台官方背书。
