# 收藏级 Doll 设计

## 设计原则

明确把结果定位为成人收藏级 fashion doll、可动玩偶或 stylized toy figure，而非真人肖像。面部、身体比例、服装、配饰、背景和材质共同构成可玩、可辨识的角色。

## 工作流

1. 收集主题或昵称、娃娃类型、风格、发型、妆容、服装、鞋包、配饰、姿态、背景、比例和用途。信息不足时给出三套预设方向。
2. 建立玩偶身份锁：头身比例、关节位置、脸部风格、材质（搪胶、乙烯基、树脂或织物）、主色、标志配件和包装外的视觉环境。
3. 设计造型变体，每个变体只改变一个主要维度，并说明收藏场景、色彩和道具关系。
4. 用户确认后生成一到多张形象图；有参考图时只吸收服装、材质、色彩或背景氛围，不复刻真人脸。
5. 检查玩偶化程度、比例、关节合理性、材质一致性、配饰数量和背景清洁度，必要时针对问题重试。
6. 交付角色卡、正面/三分之四视图提示词、变体说明和可选的高清化建议。

## 安全门

拒绝明星、网红、用户本人或未授权真人的身份复刻；“幼态”只能表示圆润、亲近和低攻击，不用于性化未成年人。不得复制 Barbie 等品牌 Logo、包装或具体系列。
