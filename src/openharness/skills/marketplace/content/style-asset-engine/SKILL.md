# 名导十五秒视频风格资产引擎

## 适用条件

需要至少一张用户有权使用的参考图，以及一句话主体动作或叙事需求。没有参考图时只做通用创意，不套用本技能的风格提取流程。技能输出风格卡、镜头方案和提示词；最终媒体生成由系统工具完成。

## 工作流

1. 识别参考图的主体、构图、景别、视角、光线质量、材质、色彩关系、颗粒或画面介质。
2. 用一句话归纳导演句法：观众先看到什么、运动如何发生、情绪如何转折、哪些信息被刻意留白。
3. 建立风格卡：视觉锚点、镜头语法、光影规则、色彩命名、材质词、可变项、禁用项和适用场景。色板只用于内部分析，不把精确色值机械塞入最终生成提示词。
4. 将动作拆成三段：建立状态、能量变化、结果或余韵。每段写主体动作、镜头运动、环境反应、声音意图和连续性锚点。
5. 向用户回顾风格锁定项和动作假设；用户确认后输出每段独立而相互衔接的提示词。
6. 若用户要求保存资产，写入项目约定的风格卡文件并保留版本和来源说明；不要写入密钥、临时 URL 或真实个人资料。
7. 生成后检查风格一致性、主体身份、动作可执行性和时长边界，必要时只调整漂移项。

## 质量门

- 风格卡描述可观察、可复核，不只使用“电影感、高级”等空泛词。
- 三段之间共享构图、光线和主体锚点，转折点清晰。
- 参考图中的品牌 Logo、人物身份和受保护作品只在用户明确授权范围内使用。
- 不在技能中直接调用第三方服务；媒体、计费、安全和 artifact 交付由后端负责。
