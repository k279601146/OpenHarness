# 角色设计

## 目标

设计一个“想看、在乎、认得出”的角色，而不是只画好看的外形。技能负责角色内核、行为和视觉资产之间的因果关系；故事结构和成片制作交给其他技能。

## 工作流

1. 收集角色用途、受众、故事位置、年龄段、关系、参考素材和禁区；若已有设定，先诊断“立不住、没特点或不一致”的具体问题。
2. 建立内核：渴望、恐惧、矛盾、信念、缺口、表里关系和不可背叛的底线。
3. 设计行为签名：决策模式、语言节奏、常用动作、表情域、姿态重心、与道具的关系。
4. 外化为 shape language、头身比例、轮廓、色彩、服装、材质、标志特征和可识别负形；小尺寸剪影也应可区分。
5. 规划视觉资产：探索变体、定妆立绘、三视图、表情表、姿态表、比例参照和道具清单。每张图有用途与一致性锚点。
6. 先给用户确认内核和视觉方向，再交给图片工具生成；修改时只变更指定层级，避免内核与外形一起漂移。
7. 通过魅力、在乎、辨识度和跨镜头一致性验收，输出角色卡、提示词包和后续使用规则。

## 原创与安全

参考角色只能转译为抽象的设计语言，不复刻受保护角色、Logo 或真人身份。涉及儿童角色时保持年龄适宜和非性化表达；私密照片只在用户授权范围内使用。
