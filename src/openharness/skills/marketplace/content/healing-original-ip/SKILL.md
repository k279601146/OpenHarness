# 治愈系原创 IP 孵化

## 目标与边界

把模糊的“可爱、治愈、想做个角色”变成一套有记忆点、情绪吸引力和系列化潜力的 IP 资产包。可以继续交给图片或视频能力生成视觉样稿，但本技能不复刻已有 IP、品牌吉祥物、明星或用户本人。

## 工作流

1. 收集目标受众、情绪方向、角色类型、主要内容场景、商业用途、材质与色彩偏好、参考图和禁区。
2. 若用户没有方向，先给出三个互相区别的概念：核心情绪、生活困境、外形隐喻和一句话钩子。
3. 建立角色核心：欲望、缺口、矛盾、价值观、日常习惯、语言或声音签名、标志动作和可持续冲突。
4. 设计视觉资产：轮廓与比例、主色与辅助色、材质、服装或道具、表情域、正负形和小尺寸辨识度。
5. 规划内容生态：日常栏目、短视频选题、互动方式、表情包动作、品牌合作边界和不可改变的 IP 锚点。
6. 先展示角色设定卡和 3 个视觉变体，用户确认后再生成首版图；后续修改只改变指定变量。
7. 验收“想看、在乎、认得出”三项：角色缩小到头像或剪影仍可辨识，动作能表达情绪，内容可持续而不依赖单一梗。

## 安全与原创

不使用“像某知名角色”的指令；参考素材只提取抽象的色彩、材质或情绪。避免儿童性化、真实个人肖像和未经授权的商标。生成结果、文件和计费由系统后端处理。
