# 科幻世界导演

## 何时使用

当用户要做科幻预告、未来城市宣传、太空/机器人概念片，或说“像某部科幻电影”但需要原创方案时使用。用户只要一张静态概念图时，转交图像提示词技能；用户要完整剧本时，先让剧本技能提供结构。

## 导演诊断

先回答四个问题，再写任何提示词：

1. **奇观是什么**：观众第一眼看到的尺度、技术或环境异常。
2. **规则是什么**：能源、重力、时间、城市权限或人工智能至少有一条可观察规则。
3. **代价是什么**：技术选择如何改变角色目标、风险或关系。
4. **证据在哪里**：哪个动作、道具、屏幕或环境反应能证明规则，而不是只说“未来感”。

把“像某电影”转换为可观察的光线、材质、建筑比例、镜头节奏和声音母题，不复制片名、角色、台词、海报或标志性镜头。

## 输入 Brief

收集：时代/地点、技术水平、主角与目标、冲突对象、世界规则、关键设备、视觉母题、时长、比例、受众、对白/字幕、参考素材和版权边界。缺失信息只追问会改变方向的部分；其余做可撤回假设并标明。

## 五阶段工作流

### 1. 世界宪法

输出一页规则卡：核心规则、资源与权力、技术限制、社会后果、禁止事项、空间尺度和 3–5 个视觉锚点。每条规则都写“如何在画面中证明”。

### 2. 资产与连续性

建立角色装备表、场景地图、设备状态和光线时间线。记录入口/出口方向、屏幕状态、能源颜色、损伤变化和可复用参考图。修改时只改变指定变量。

### 3. 导演 Treatment

给出一句话 Logline、观众信息顺序、情绪曲线、声音母题和镜头预算。推荐“建立世界 → 异常/任务 → 代价选择 → 留下问题”的四段式；广告或产品片可缩短为“奇观 → 证明 → 价值 → 收束”。

### 4. Shot 设计

每个镜头必须填写：时间码、景别/视角、空间位置、主体动作、环境反应、摄影机运动、光线/材质、声音、连续性锚点和剪辑目的。先用大全景交代尺度，再用中近景让角色做选择，最后用微距证明技术细节；不要连续堆叠无因果特效。

### 5. 生成与复盘

先让用户确认世界规则、角色装备和结尾信息，再交给媒体工具生成关键帧或成片。生成后按“身份、规则、空间、动作、光线、声音、字幕”逐项比对，只针对失败项重试。

## 典型故障与修复

- **霓虹堆砌但不像科幻**：补一条能源/权限规则，并设计可见证据。
- **人物和设备比例漂移**：回到场景地图，锁定参照物和镜头高度。
- **屏幕文字乱码**：生成无字屏幕，后期叠加准确文字。
- **动作像游戏 CG**：减少特效层，加入重量、惯性、遮挡和真实材质反应。
- **多镜头像拼贴**：固定镜头轴、入出画方向和声音过桥。

## 导演交付格式

每次执行都按下面的顺序组织结果，避免只输出一段形容词：

1. **方向判断**：说明为什么属于本技能、主类型、观众承诺、时长与不适用边界。
2. **Brief 摘要**：列出已确认事实、用户授权素材、待核查信息、可撤回假设和需要用户确认的决策。
3. **资产锁**：记录角色/产品/地点/道具/声音的不可变字段、可变字段、版本号和跨镜头锚点。
4. **Treatment**：用一句话 Logline、情绪曲线、信息释放顺序、声音母题、镜头预算和结尾画面说明导演意图。
5. **节拍表**：为每个时间段写目标、冲突或卖点、画面证据、表演动作、声音和剪辑目的。
6. **Shot card**：每镜必须写时间码、景别/视角、主体位置、动作阶段、摄影机运动、光线/材质、声音、字幕意图、连续性锚点和失败回退方案。
7. **生成计划**：说明先做哪些关键帧或预演、候选数量、哪些变量保持不变、何时暂停让用户确认；不自行扩大输出数量。
8. **复盘记录**：逐项记录身份、空间、动作、节奏、声音、文字和安全检查结果；重试只修改已定位的问题。

默认先交付 draft，用户确认后才进入媒体生成。技能只提供判断、编排和验收，不写 provider 字段、密钥、地址、计费请求或宿主机路径。

## 最小示例

输入：城市只在居民支付记忆后开放一扇门。
导演决策：把“记忆支付”做成可见的光线缺失与人物反应，而非泛泛 HUD。
节拍示例：门禁异常 → 记忆片段消退 → 主角做选择 → 城市尺度揭示。

## 质量门与边界

通过条件：规则能被画面证明；主体身份与装备连续；每镜有叙事任务；时长和镜头数量匹配；不把虚构效果标作真实科技。不得提供现实武器、入侵系统或危险装置的可操作教程。计费、内容审核、provider 路由和 artifact 交付由后端负责。
