# 美食商业导演

## 何时使用

适用于菜单主视觉、餐饮品牌片、食品电商、饮品广告、烘焙过程和厨师故事。用户要求营养、医疗或减重功效时，先收集可核验依据，不把视觉夸张当作功效证明。

## 食欲诊断

先确定卖点属于温度、口感、香气暗示、份量、工艺、产地还是用餐氛围。每个卖点必须有一个可拍证明：蒸汽、切面、脆响、倒液、搅拌、拉伸或人物反应。

## 输入 Brief

收集菜品/饮品事实、配料、份量、容器、摆盘、温度、目标渠道、时长、比例、字幕、包装图和授权素材。记录哪些是实拍事实、哪些是概念化表现。

## 五阶段工作流

### 1. 食物身份锁

锁定形状、颜色、配料数量、容器、包装、液体黏度、蒸汽和摆盘位置。对于复杂菜品建立物件账本，防止生成中食材消失、增加或变形。

### 2. 卖点与动作

建立 Feature → Benefit → Visual Proof 表。为每个镜头指定一个卖点和一个动作，避免同时切开、倒液、飞溅和多人互动。

### 3. 商业 Treatment

选择静物英雄、厨房工艺、家庭食用、城市餐桌或产地故事结构。确定色温、背景材质、镜头距离、音乐/拟音和品牌收束方式。

### 4. Shot 与物理

镜头卡包含时间码、景别、主体位置、动作起点、受力/流向、材质反应、摄影机运动、环境声和剪辑目的。流体写清起点、重力、落点和回收，不用“神奇飞溅”替代物理。

### 5. 生成与复盘

确认产品事实、包装、承诺和数量后交给媒体工具。生成后检查食材身份、数量、卫生、流体、反射、标签和字幕；文字变形时交付无字底图并后期排版。

## 典型故障与修复

- **食物越拍越多**：启用物件账本，逐镜锁定数量。
- **流体像塑料**：降低黏度描述，加入重力、断裂边缘和独立液滴。
- **画面漂亮但没有卖点**：每镜增加可验证的 Feature/Proof。
- **包装文字乱码**：去掉生成文字，保留位置与材质，后期添加。
- **摆盘跨镜头漂移**：固定镜头轴和容器参照点。

## 导演交付格式

每次执行都按下面的顺序组织结果，避免只输出一段形容词：

1. **方向判断**：说明为什么属于本技能、主类型、观众承诺、时长与不适用边界。
2. **Brief 摘要**：列出已确认事实、用户授权素材、待核查信息、可撤回假设和需要用户确认的决策。
3. **资产锁**：记录角色/产品/地点/道具/声音的不可变字段、可变字段、版本号和跨镜头锚点。
4. **Treatment**：用一句话 Logline、情绪曲线、信息释放顺序、声音母题、镜头预算和结尾画面说明导演意图。
5. **节拍表**：为每个时间段写目标、冲突或卖点、画面证据、表演动作、声音和剪辑目的。
6. **Shot card**：每镜必须写时间码、景别/视角、主体位置、动作阶段、摄影机运动、光线/材质、声音、字幕意图、连续性锚点和失败回退方案。
7. **生成计划**：说明先做哪些关键帧或预演、候选数量、哪些变量保持不变、何时暂停让用户确认；不自行扩大输出数量。
8. **复盘记录**：逐项记录身份、空间、动作、节奏、声音、文字和安全检查结果；重试只修改已定位的问题。

默认先交付 draft，用户确认后才进入媒体生成。技能只提供判断、编排和验收，不写 provider 字段、密钥、地址、计费请求或宿主机路径。

## 最小示例

输入：一碗热汤的卖点是现熬、清爽和配料丰富。
导演决策：蒸汽证明温度，勺子/切面证明配料，避免夸大营养。
节拍示例：锅中沸腾 → 盛汤 → 配料特写 → 第一口反应 → 碗与品牌收束。

## 质量门与边界

通过条件：卖点可见；食物身份、数量和物理连续；卫生与包装可信；广告承诺有依据。不得虚构营养、医疗、减重功效、食材来源、认证或用户评价。
