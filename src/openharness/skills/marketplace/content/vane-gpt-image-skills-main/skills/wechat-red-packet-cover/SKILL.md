# 微信红包封面制作

## 工作方式

按用户要求制作，每次默认只做一张。用户可以描述主题、颜色、风格、祝福文字，也可以提供照片、宠物或其他参考图。缺少非关键细节时自行设计；有参考人物或形象时尽量保留其可辨识特征。用户不指定风格时可参考 [风格目录](references/styles.md)，也接受目录以外的方向。`assets/style-gallery/` 的四张九宫格是风格展示，并非制作流程的默认输出。

1. **制作原图。** 使用当前环境可用的图片生成或编辑工具生成单张 3:4 竖图；先检查工具是否实际可用。以完整封面画面为交付目标，上部头像、昵称、祝福语及下部按钮附近保留适当空间，关键主体避免被遮挡。除非用户指定画中文字，否则不加字；不要把微信头像、按钮、红包下摆画进原图。对于用户提供的图片，按要求保留重要元素并调整构图。没有图片生成能力时说明限制，可提供设计提示词，但不要假称已生成图片。
2. **展示原图并等待确认。** 每次展示图像和文件路径；用户可以指出具体修改。未经用户确认，不进入红包效果预览。用户明确要求一次完成时遵从用户指示。
3. **制作模拟红包效果图。** 对用户确认的原图先导出临时 957 × 1278 图片，再用下面的 `preview` 命令合成固定界面。不要通过重新绘制原图来模拟预览。默认使用示例头像、昵称和祝福语；用户可以指定内容。预览是近似示意，非微信官方模板，实际位置和裁切以微信平台为准。将预览展示给用户并等待确认。
4. **按反馈调整。** 如被遮挡或用户不满意，修改原图，再重新展示、确认并制作预览。
5. **导出交付。** 确认效果后用 `export` 输出 957 × 1278、最大 500,000 字节的 JPEG；交付原图、上传文件、模拟预览图的本地路径和尺寸/大小。说明实际上传规范与预览应以微信平台为准，不承诺审核通过。默认不上传、不发布、不操作账号。

## 本地处理

需要 Python 3 和 Pillow（`python3 -m pip install Pillow`）。以下 `<skill-dir>` 是当前 `SKILL.md` 所在目录；从用户选定的原图创建新文件，不覆盖输入。

```bash
python3 '<skill-dir>/scripts/cover_tool.py' export '封面原图.png' '上传封面.jpg'
python3 '<skill-dir>/scripts/cover_tool.py' preview '上传封面.jpg' '红包预览.png' --name '微信用户' --greeting '恭喜发财，大吉大利'
```

`export` 默认居中裁剪到 3:4 再缩放，避免拉伸；裁剪可能改变构图，必须在交付或预览前核查画面。处理后检查输出并告知用户。需要自定义裁剪位置或保留完整画面时，按用户意图先做图片处理再运行，不强行居中。JPEG 默认使用白底处理透明区域；需要透明封面时和用户确认适合的输出格式。预览需要可显示中文的字体：macOS、Windows、常见 Linux 字体路径会自动查找；若不存在，可用 `--font` 指向本机中文字体。预览图是演示图，不能当作上传素材。
