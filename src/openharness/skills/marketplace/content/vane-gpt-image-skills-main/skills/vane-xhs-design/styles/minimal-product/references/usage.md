# 极简产品风小红书图文 Skill

把一段文字与用户照片或 AI 示意配图，制作成九页白底、统一主体的极简海报图文。流程为内容与配图方式选择、九宫格和逐页文字确认、逐张生成 9 张独立图。

在支持 Agent Skills 且具备图片生成／参考能力的客户端，安装合集中的 `vane-xhs-design`，并选择极简产品风。调用示例：

> 使用极简产品风图文 Skill，把以下文字做成九页小红书笔记。我选择文字＋AI 配图：……

也可选择“文字＋用户图片”并附图。预览及独立图默认 3:4，用户确认九宫格和文案后再生成单图。字体和布局为视觉近似，中文、真实素材、页数和尺寸需逐项检查。不同客户端的安装目录和图片能力不同，缺少图片生成能力时不能生成图片。

分享本 Skill 参考素材之前，确认相关素材可供再分发；本目录不包含官方 Grok Bot 图片或标识素材。
