# 宠物新年写真

把同一只宠物的参考照片变成一套风格统一、画面有变化的新年写真。默认交付九张分别生成、分别保存的独立写真。若用户希望先看风格、讨论设计或明确要求预览，可先生成白底、整体竖版 3:4 的 3×3 九宫格供选片；预览不是独立成片。用户选定整组或指定画面时，结合宠物原始参考图，逐张生成对应的独立写真。

## 输入与默认值

- 必须取得至少一张清晰可辨识宠物面部的正面或近正面照片；用户未提供时，请其上传。照片模糊、脸被遮挡、特征难辨时，说明问题并请用户补充。不要凭文字虚构成用户宠物。
- 正面、侧面、背面三视图是可选项，不是门槛；多图应属于同一只宠物。区分各图用途：正面用于脸部与眼睛等识别特征，侧面和背面用于可见的体型、毛色及花纹。无法确定多图是否同一只时先问清。仅一张正面照时，未见的背面特征不应被宣称为准确；优先以正面和三分之二视角设计。
- 用户已有配色、氛围、道具、服饰、禁忌或参考风格时遵循；未指定时采用喜庆、精致、写实的中国春节影棚风格，以红、暖白和少量金色为主。不自作主张增加文字、生肖年份、人的角色或第二只宠物。
- 用户指定生肖时，将对应生肖明确融入服装、玩偶、剪纸或布景，并让每张同时保留春节气氛和宠物可辨识的脸部特征；服从用户指定，不自行推测生肖或年份。
- 背景可以采用白色、中国红、黑金或用户指定的摄影棚色系，适量搭配拱门、台座、窗棂和节庆道具；保证宠物和背景有足够区分，白毛在白底要有层次，黑底要照亮面部。预览板的白色与照片内的摄影背景是两个独立设置。
- 默认逐张输出九张单独写真，未指定单张比例时采用竖版 3:4；用户要求其他数量或比例时遵循用户要求。只有用户希望预览时才先输出九宫格：白色竖版底板整体为 3:4，三行三列、九个等大画面、规整白色间距与白色外边距；不添加标题、水印和编号。

## 工作流程

1. 观察参考照片，提炼可见的种类、毛色、眼睛、脸型、耳朵、鼻子、花纹、毛长和体态。忠于实际影像，不猜测品种或未见的特殊标记。将这些特征作为所有画面共享的身份约束。保持宠物自然解剖，避免换脸、换毛色、增加肢体或让装饰遮挡主要特征。
2. 规划同一主题下的九个不同画面，变化可来自坐姿、视线、景别、灯光和安全自然的节庆道具；保持同一只宠物和统一的摄影质感。九张照片应穿插近景、中景和中远景：可按 2 张头部至胸部近景、4 张中景、3 张包含部分布景的全身中远景规划；若制作预览则在三行中交错安排，避免相同景别扎堆。远景以能看清宠物脸部与全身的中远景为准，猫狗等主体通常应占单格画面高度约 50%～75%，道具和布景只作为陪衬；避免主体过小的超远景或大量空景。近景需要完整呈现宠物头部、双耳及部分胸部，保留可辨认的新年装饰；禁止脸部或眼睛占满画面的超特写、裁掉双耳或把脸挤出画框。各景别应呈现适度的尺度差异；用户指定景别或排列时优先遵循。每一张都要有清晰可辨的春节元素，如红灯笼、红包、中国结、年花、红色节庆服饰或金元宝；风格和配色可以变化，但不能让场景盖过新年主题。用户另有要求时优先遵循。道具与服装不能改变宠物身份，避免画面重复或单张多只宠物。生成前为九张逐一规划身体姿势，同一或相近姿势最多出现两张；仅换镜头、视线、服装或道具不算新的姿势。根据宠物种类自然安排坐、站、趴、走、回头、伸爪或与道具互动等动作，避免不自然的强迫姿势；生成后逐张复核姿势重复度，明显超出时有针对性重做。
3. 使用当前环境可用的图片生成或图片编辑工具，将所有用户提供的参考图传入并标明各自作用；本环境优先使用内置 image_gen。用户上传的是身份参考图，不是仅供文字描述的素材。尊重工具对本地图片、会话附件和多图引用的要求；不可把没有实际传入图片的纯文生图说成参考生成。若工具不可用或无法传入图片，应说明限制，不冒称完成。
4. 确定用户当前要求：默认对九个画面分别调用图片生成工具，产出九张独立文件；如果用户要求先预览，才生成一张 3×3 九宫格。预览底板明确为整体竖版 3:4、纯白、等大格子和白色间距；预览不能冒充独立原图。
5. 如用户指定预览中的某几格或整组，使用宠物原始照片及选定预览作为不同角色的参考，逐张生成对应画面：每次明确位置、姿势、服装、道具、构图以及要输出一张完整独立照片，禁止输出拼图。重新生成可能存在细节偏差，不宣称像素级一致，也不把低分辨率裁切放大冒充高清。若无预览，按第 2 步逐张生成。
6. 逐张目视检查宠物主体相似度、眼色与毛色、自然解剖、春节元素、姿势重复度与画面完整性；检查实际像素比例。明显错误时有针对性重做。不能保证一次完全还原，未见角度也可能有偏差。单张写真应完整铺满画面，不得为强凑比例擅自加白边；如无法输出指定比例，应说明真实尺寸与限制。
7. 将每张独立写真分别保存并清晰编号，在对话中提供图片或文件路径；在具备条件时一并提供整套下载，并报告实际尺寸和比例。仅当用户要求预览时，才展示九宫格，并说明它的用途。检查精确 3:4 仅对预览底板需要时，使用本技能自带画布脚本，不得以此修复内容问题。

## 本地比例处理

仅用于九宫格预览底板，图片生成工具若不能直接满足精确比例，可运行：

```bash
python3 scripts/fit_white_canvas.py INPUT_IMAGE OUTPUT_IMAGE
```

默认输出 1200×1600 PNG；脚本保留原图、不覆盖已存在文件、缩放后居中放在白色画布上。用户要求其他尺寸时可使用 `--width` 和 `--height`，两者需构成 3:4。比例校准不等于视觉质量合格，仍需检查画面。
